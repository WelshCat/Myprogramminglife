# 주간 알람 (안드로이드)

월~일 요일별 알람을 한 번에 정해 두고, 본 알람 **1~2시간 전부터 15분 간격으로 미리 알람**이 울리는 알람 앱입니다.

<img src="icon/icon-512.png" width="96" alt="앱 아이콘">

- Android 8.0 이상, 외부 라이브러리 없음, 인터넷 사용 안 함

## 기능
- **요일별 알람**: 요일마다 하나, 00:00~23:59. 매주 반복
- **타이핑 없는 시간 설정**: 시/분 휠 + ±10분/±1시간 버튼, 여러 요일 한 번에 적용 (평일/주말/매일)
- **미리 알람**: 본 알람 30분/1시간/1시간30분/2시간 전부터 5/10/15/20/30분 간격 (끄기 가능)
  - 미리 알람을 끄면 그 하나만 꺼지고 다음 간격에 또 울림
  - "남은 미리 알람 건너뛰기" 버튼 (본 알람은 항상 울림, 설정에서 숨기기 가능)
- **다시 알림(스누즈)**: 본 알람에만, 기본 꺼짐. 간격·최대 횟수 설정
- **알람음**: 시스템 알람음 또는 내 음악 파일, 알람 음량, 점점 크게, 진동, 울림 시간
- **해제**: 잠금 화면 위 전체 화면, 가운데 원을 바깥으로 밀어서 해제 (갤럭시 기본 알람 방식)
- **새로운 한 주 알림**: 매주 월요일 00:00 (변경 가능) — 지난주 설정을 유지한 채 확인/변경 안내

## 반드시 울리게 하는 안전장치
| 위험 | 대응 |
|---|---|
| 절전/Doze로 지연 | `setAlarmClock` (알람 시계 등급 예약, 절전 무시) |
| 예약이 사라짐 | 1분 뒤 **보조 예약** + 15분마다 **감시 작업**이 다시 예약. 중복 울림은 자동 방지 |
| 울리는 중 오류 | 알람 도착 시 **다음 알람부터 먼저 예약**한 뒤 소리를 냄 |
| 재부팅 | 잠금 해제 **전**에도 다시 예약·울림 (Direct Boot) |
| 휴대폰이 꺼져 있었음 / 시간 변경 | 놓친 본 알람을 60분 이내면 **즉시** 울림 (끄기 가능), 그 이상이면 놓친 알람 알림 |
| 알람음 파일 오류 | 선택한 소리 → 기본 알람음 → 다른 시스템 소리 → **앱이 만든 비프음** 순서로 자동 전환 |
| 알람 음량 0 / 무음 모드 | 울리는 동안만 설정 음량으로 올렸다가 복원, 알람 스트림 사용 |
| 울림 서비스 시작 실패 | 소리가 끝없이 반복되는 **비상 알림**으로 대체 |
| 권한/배터리 설정 문제 | 첫 화면 **점검 카드**에서 확인·해결, 실제 시스템 예약 여부도 확인 |

시간 계산 로직(`Planner.kt`)은 안드로이드에 의존하지 않으며, 자정·주 경계·서머타임·놓친 알람·중복 방지·
일주일 연속 시뮬레이션 등 21개 시나리오로 검증했습니다.

## 설치 후 꼭 할 것
1. 알림 권한 허용
2. 첫 화면 점검 카드의 항목을 모두 해결 (특히 **배터리 최적화 제외**)
3. 삼성: 설정 › 배터리 › 백그라운드 사용 제한 › **절전 예외 앱**에 추가
4. **테스트 알람 (1분 뒤)** 으로 화면을 끈 상태에서 울리는지 확인

## 빌드
```bash
cd alarm && ./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
APK는 `keystore/weekalarm.jks` 고정 키로 서명되어, 새 버전을 덮어서 설치할 수 있습니다
(직접 설치용 키이며 스토어 배포용이 아닙니다).
